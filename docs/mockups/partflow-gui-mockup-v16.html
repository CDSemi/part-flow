    Work Orders

    Manual Work Order entry and explicit production release. Saving demand never creates production quantity — physical quantity enters production only through the explicit Release to production action on a demand line. Select a Work Order to open its details.
    WO NumberReceivedDue dateDemand linesStatus

    Work Order Details

    ● Unsaved changes
    Demand lines — each line's due date defaults to the WO due date and may be edited per line. Edits stay an unsaved draft until Save demand.
    Scan a PN barcode — it carries the PN itself (demo: PF:PN:78-04-0031 · PF:PN:309-127 · a PN outside the catalog, e.g. PF:PN:NEW-PART-01, is created on first use) — or add a line manually to look up / create a PN. A new line joins this Work Order as an unsaved draft — Request Type NEW, due date from the WO due date. A PN already on this Work Order focuses its existing line instead of adding a duplicate.
    A demand line can be removed only while no production quantity has been released for it — a released line stays; later adjustments go through the correction workflows. Removal never deletes the Part, its production quantity, or its history.
